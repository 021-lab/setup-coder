# Как это попадает в окружение

Облачная сессия поднимает свежий контейнер: всё, что не лежит в репозитории,
теряется между чатами. Отсюда два пути.

## Setup script окружения — основной

Меню облачного окружения в шапке сессии → **Edit** → **Setup script**:

```bash
set -eu
TMP=$(mktemp -d)
git clone --depth 1 --branch v1 https://github.com/021-lab/setup-coder "$TMP/src" || exit 0
"$TMP/src/setup-coder.sh" --env
rm -rf "$TMP"
```

Что происходит: `CLAUDE.md` → `$HOME/.claude/CLAUDE.md`, каталоги из `skills/` →
`$HOME/.claude/skills/`, серверы из `mcp.json` → пользовательский конфиг
командой `claude mcp add --scope user`.

Скрипт привязан к окружению, а не к чату: все чаты этого окружения получают
настройки. Окружений может быть несколько — строки нужны в каждом.

### Проверено на этом контейнере

- Запись в `$HOME/.claude/CLAUDE.md` из Setup script **переживает** старт сессии,
  и файл попадает в контекст агента, а не просто лежит на диске.
- `claude mcp add --scope user` пишет `mcpServers` в `~/.claude.json`. Повторный
  вызов для уже настроенного сервера печатает `already exists` и возвращает **1** —
  установщик разбирает это по тексту и не считает ошибкой.
- Скилл, положенный в `$HOME/.claude/skills/`, становится доступен агенту.

### Чего знать нельзя заранее

- **Сеть.** `git clone` на старте зависит от сетевой политики окружения. `|| exit 0`
  оставлен нарочно: без сети окружение поднимется без настроек, причина уйдёт в
  лог старта, а факт установки видно в `$HOME/.claude/.setup-coder`.
- **Безопасность.** Setup script выполняет код из публичного репозитория при
  каждом старте. Поэтому клон прибит к тегу `v1`: правка в `main` не уезжает во
  все окружения мгновенно, а только когда тег передвинут — см.
  [Версии](releases.md).

## Репозиторий проекта — когда нужна воспроизводимость

```bash
setup-coder.sh --repo /путь/к/проекту
```

Настройки коммитятся в проект и достаются каждому, кто его открыл, включая тех,
кто работает не из вашего окружения. И остаются привязанными к коммиту: видно,
какие правила действовали, когда что-то ломалось. Через окружение этого не
добиться.

`.mcp.json`, пришедший из репозитория, Claude Code показывает на подтверждение
при первом использовании — так сделано нарочно, чтобы чужой репозиторий не
запускал процессы без спроса. Один раз подтвердить придётся.
