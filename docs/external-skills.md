# Внешние инструменты

Три вещи, которые не живут в этом репозитории: их ставят один раз в Claude Code,
а `CLAUDE.md` только говорит, когда их грузить. Держать их в контексте постоянно
не нужно и дорого.

## Superpowers

Плагин Джесси Винсента: брейншторм спеки → план → выполнение с TDD и ревью между
шагами. Оттуда же берётся `/verify` — скилл `verification-before-completion`,
который запрещает говорить «готово» без запущенной команды и её вывода.

```
/plugin install superpowers@claude-plugins-official
```

Если официального маркетплейса нет:

```
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace
```

Проверить: `/plugins` — в списке должен быть `superpowers`.

Полное имя команды проверки, если короткого `/verify` нет:
`/superpowers:verification-before-completion`.

- Репозиторий: https://github.com/obra/superpowers-marketplace
- Как автор это задумывал: https://blog.fsck.com/2025/10/09/superpowers/

**Когда грузить:** задача многошаговая и её не стыдно назвать проектом. Для
правки в две строки это лишний вес.

## Context7 — ставится установщиком

MCP-сервер Upstash: подтягивает официальную документацию нужной версии
библиотеки в момент запроса, вместо того чтобы модель вспоминала API по памяти.

Руками ничего делать не нужно: сервер описан в `mcp.json` этого репозитория, и
`setup-coder.sh` сам ставит его — в `--env` командой
`claude mcp add --scope user`, в `--repo` записью в `.mcp.json` проекта.

Использование: дописать `use context7` в запрос, либо сразу назвать библиотеку.

### Ключ обязателен на практике

Проверено на облачном контейнере: сервер поднимается и инструменты отвечают, но
на первый же запрос без ключа приходит `Monthly quota exceeded`. Бесплатная
квота считается по адресу, а облачные контейнеры делят адрес между всеми — так
что она исчерпана практически всегда.

Ключ берётся бесплатно на https://context7.com/dashboard и кладётся в **секреты
окружения** под именем `CONTEXT7_API_KEY`. Сервер читает его сам из переменной
окружения; в `mcp.json` ничего менять не нужно.

Именно переменная, а не флаг `--api-key`: аргумент командной строки виден в
списке процессов любому, кто смотрит `ps`.

- Сайт и ключ: https://context7.com/dashboard
- Пакет: https://www.npmjs.com/package/@upstash/context7-mcp
- Документация для Claude Code: https://context7.com/docs/clients/claude-code

**Когда грузить:** пишем код под внешнюю библиотеку или API — особенно если
версия свежее, чем обучающие данные модели.

## webapp-testing — ставится установщиком

Скилл Anthropic: управление настоящим браузером через Playwright. Клики,
авторизация, JS-рендер, инспекция DOM, скриншоты, логи консоли, запуск и
остановка локальных серверов.

Копия лежит в `skills/webapp-testing/` этого репозитория вместе с лицензией и
файлом `VENDORED.md`, где записан коммит источника. Установщик кладёт её туда,
куда ставит остальные скиллы. Обновление — заменить каталог свежей копией из
https://github.com/anthropics/skills/tree/main/skills/webapp-testing и поправить
`VENDORED.md`.

Требует Playwright. В облачном контейнере Claude Code Chromium уже стоит, и
`PLAYWRIGHT_BROWSERS_PATH` настроен — отдельно ставить браузер не нужно.

Проверено: после установки в окружение скилл виден агенту в новой сессии.

**Когда грузить:** надо увидеть фронтенд живьём, а не поверить тестам. Для CI
это не предназначено — туда пишется обычный Playwright-тест.

## Что ставится само, а что руками

| | Как |
| --- | --- |
| Context7 | установщиком, из `mcp.json` |
| webapp-testing | установщиком, копия в `skills/` |
| Superpowers | **руками**: это плагин Claude Code, командой `/plugin install` |

Плагин установщиком не поставить: плагины живут в конфигурации Claude Code, и
их установка — интерактивная команда, а не файл.
