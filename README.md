# setup-coder

Общие настройки агента: правила, единые для всех проектов, и скиллы, которые
нужны не одному репозиторию. Здесь они правятся в одном месте, а
`setup-coder.sh` раскладывает их по репозиториям проектов.

## Что лежит

| Файл | Что это |
| --- | --- |
| `CLAUDE.md` | Общие правила работы агента. Попадают в `CLAUDE.md` проекта блоком между маркерами. |
| `skills/` | Общие скиллы, каталог на скилл. Попадают в `.claude/skills/` проекта. |
| `setup-coder.sh` | Раскладывает и то и другое по указанному репозиторию. |

## Как разложить по проекту

```bash
git clone --depth 1 https://github.com/021-lab/setup-coder /tmp/setup-coder
/tmp/setup-coder/setup-coder.sh /путь/к/проекту     # без аргумента — текущий каталог
```

Посмотреть, что изменится, ничего не записывая:

```bash
/tmp/setup-coder/setup-coder.sh --check /путь/к/проекту
```

Дальше изменения коммитятся в репозиторий проекта как обычно. `CLAUDE.md` в
корне репозитория читается агентом в любой сессии сам — ни настроек, ни хуков
для этого не нужно.

## Что скрипт не портит

- **Правила проекта.** Общие правила вставляются блоком между маркерами
  `setup-coder: начало` и `setup-coder: конец`. Всё, что написано в `CLAUDE.md`
  проекта вне блока, остаётся нетронутым; при повторном запуске обновляется
  только блок.
- **Чужие скиллы.** Скилл из `skills/` заменяется в проекте целиком — иначе
  файл, удалённый здесь, остался бы жить там. Скиллы, которых здесь нет,
  не трогаются.
- **Повторный запуск.** Безопасен: что совпадает — то не переписывается.

## Автоматически в каждой сессии

Каждая облачная сессия поднимает свежий контейнер, поэтому всё, что не лежит в
репозитории, теряется. Два способа не раскладывать руками:

1. **Разложить один раз и закоммитить** — `CLAUDE.md` и `.claude/skills/`
   приезжают вместе с клоном проекта. Ничего настраивать не нужно.
2. **Setup script окружения** — если правила нужны и там, где репозитория
   проекта нет. Меню облачного окружения в шапке сессии → Edit → Setup script:

   ```bash
   git clone --depth 1 https://github.com/021-lab/setup-coder /tmp/setup-coder
   mkdir -p ~/.claude/skills
   cp /tmp/setup-coder/CLAUDE.md ~/.claude/CLAUDE.md
   cp -R /tmp/setup-coder/skills/. ~/.claude/skills/ 2>/dev/null || true
   ```

   Скрипт окружения настраивается отдельно для каждого окружения.

Клонирование без ключей работает, только пока репозиторий публичный. Если он
приватный, понадобится токен на чтение в секретах окружения и адрес вида
`https://x-access-token:$TOKEN@github.com/021-lab/setup-coder`.
