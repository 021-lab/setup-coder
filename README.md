# setup-coder

Стандартное окружение агента: правила поведения, скиллы и MCP-серверы. Правятся
здесь, ставятся одной командой — в окружение при старте контейнера или в
репозиторий проекта.

```
CLAUDE.md          правила: поведение, шаг работы, формат отчёта
skills/            скиллы, каталог на скилл
mcp.json           MCP-серверы, которые нужны всегда
setup-coder.sh     установщик, два режима
docs/              справка про сам этот репозиторий, никуда не копируется
```

## В окружение — основной путь

В **Setup script** окружения (меню окружения в шапке сессии → Edit):

```bash
set -eu
TMP=$(mktemp -d)
git clone --depth 1 --branch v1 https://github.com/021-lab/setup-coder "$TMP/src" || exit 0
"$TMP/src/setup-coder.sh" --env
rm -rf "$TMP"
```

Ставит в `$HOME/.claude`: правила, скиллы, MCP-серверы на пользовательский
уровень. Каждый новый чат этого окружения поднимается уже настроенным,
репозиторий проекта при этом не трогается вообще.

Клон прибит к тегу `v1`, а не к `main`: правка в `main` уезжает в окружения
только когда вы передвинете тег — см. [Версии](docs/releases.md).

`|| exit 0` намеренный: нет сети — окружение всё равно поднимется, а причина
уйдёт в лог старта. Что и когда поставилось, видно в `$HOME/.claude/.setup-coder`.

## В репозиторий проекта — когда настройки нужны всем

```bash
git clone --depth 1 https://github.com/021-lab/setup-coder /tmp/setup-coder
/tmp/setup-coder/setup-coder.sh --repo /путь/к/проекту   # без пути — текущий каталог
/tmp/setup-coder/setup-coder.sh --repo /путь --check     # только показать, что изменится
```

Кладёт `CLAUDE.md`, `.claude/skills/` и `.mcp.json` в проект; дальше это
коммитится. Нужно, когда настройки должны достаться каждому, кто открыл
репозиторий, и быть воспроизводимыми: «на этом коммите действовали такие
правила». Через окружение так не получится — там всегда свежий `main`.

Режимы не конкурируют: общие правила — в окружение, правила конкретного
проекта — в его репозиторий.

## Что установщик не портит

- **Правила проекта.** В режиме `--repo` общие правила вставляются блоком между
  маркерами `setup-coder: начало` и `setup-coder: конец`; всё вне блока остаётся
  как было.
- **Чужие MCP-серверы.** `.mcp.json` сливается: наши серверы добавляются, чужие
  и прочие поля файла сохраняются.
- **Чужие скиллы.** Скилл из `skills/` заменяется целиком — иначе файл,
  удалённый здесь, остался бы жить на месте установки. Скиллов, которых здесь
  нет, установщик не касается.
- **Повторный запуск.** Безопасен в обоих режимах: что совпадает — не
  переписывается, уже настроенный MCP-сервер не считается ошибкой.
