# setup-coder

Настройки агента, общие для всех проектов. Правятся здесь, раскладываются по
репозиториям проектов скриптом.

```
CLAUDE.md          то, что уезжает в проекты: правила поведения, формат отчёта,
                   шаг работы, список внешних инструментов
setup-coder.sh     раскладывает CLAUDE.md и skills/ по указанному репозиторию
skills/            собственные скиллы, каталог на скилл
docs/              справка про сам этот репозиторий, в проекты не копируется
```

## Разложить по проекту

```bash
git clone --depth 1 https://github.com/021-lab/setup-coder /tmp/setup-coder
/tmp/setup-coder/setup-coder.sh /путь/к/проекту     # без аргумента — текущий каталог
/tmp/setup-coder/setup-coder.sh --check /путь       # только показать, что изменится
```

Дальше изменения коммитятся в проект. `CLAUDE.md` в корне репозитория читается
агентом в любой сессии сам — ни настроек, ни хуков для этого не нужно.

## Что скрипт не портит

- **Правила проекта.** Общие правила вставляются блоком между маркерами
  `setup-coder: начало` и `setup-coder: конец`. Всё, что написано в `CLAUDE.md`
  проекта вне блока, остаётся нетронутым; повторный запуск обновляет только блок.
- **Чужие скиллы.** Скилл из `skills/` заменяется в проекте целиком — иначе
  файл, удалённый здесь, остался бы жить там. Скиллы, которых здесь нет, не
  трогаются.
- **Повторный запуск.** Безопасен: что совпадает — то не переписывается.
