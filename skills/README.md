# Собственные скиллы

Каталог на скилл, внутри `SKILL.md`:

```
skills/
  deploy-verify/
    SKILL.md
```

`setup-coder.sh` копирует каждый такой каталог в `.claude/skills/` целевого
репозитория и заменяет его целиком, чтобы удалённый здесь файл не остался жить
в проекте. Скиллы проекта, которых здесь нет, скрипт не трогает.

Сюда кладутся только **свои** скиллы. Superpowers, Context7 и webapp-testing —
плагин, MCP-сервер и внешний скилл: они ставятся в Claude Code, а не копируются
в репозиторий, и описаны в [docs/external-skills.md](../docs/external-skills.md).

Пока своих скиллов нет — этот файл держит каталог в git.
